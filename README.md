# Fake Drug Text/Barcode Checker Using Machine Learning

## Overview

This project presents a machine-learning prototype for screening medicine
information against a reference dataset of registered pharmaceutical products.

The project uses a NAFDAC registered-product dataset supplied for the capstone.
Pandas is used for data loading, cleaning and preparation, while Scikit-learn
is used to train and evaluate a Random Forest classification model.

## Objective

The main objective is to develop a prototype that can classify constructed
medicine records as either Genuine or Suspicious based on their similarity to
registered reference information.

## Dataset

The project uses the supplied NAFDAC registered-product Excel dataset.

Important fields include:

- Product Name
- Active Ingredients
- Product Category
- NAFDAC Registration Number
- Form
- Route of Administration
- Strengths
- Status

## Label Construction

The original reference records are labelled Genuine for this experiment.

Because the supplied dataset does not contain laboratory-confirmed counterfeit
labels, Suspicious examples are synthetically generated by modifying selected
fields such as:

- Product name
- NAFDAC registration number
- Active ingredients
- Dosage form

Therefore, the model should be regarded as a research screening prototype and
not as a regulatory or laboratory counterfeit-drug authentication system.

## Machine Learning

The project uses a Random Forest Classifier from Scikit-learn.

The model uses:

- Name similarity
- Registration-number match
- Ingredient match
- Form match
- Route match
- Strength match
- Category match
- Status validity

## Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
